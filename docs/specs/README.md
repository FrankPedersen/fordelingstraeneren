# Specer

Afsluttede specer til Fordelingstræneren. De levende beskrivelser bliver i roden: [SPEC.md](../../SPEC.md) og sporenes specer ([SPEC-farvebehandling.md](../../SPEC-farvebehandling.md), [SPEC-pointregnskab.md](../../SPEC-pointregnskab.md) og [SPEC-haandevaluering.md](../../SPEC-haandevaluering.md)). Appen udgiver kun det byggede, så specerne kommer ikke på hjemmesiden.

- [SPEC-navigation.md](SPEC-navigation.md) – forsidens grupper Optælling, Spilføring og Vurdering (udgivet 6. oktober 2026).
- [SPEC-tema.md](SPEC-tema.md) – temaet: `accent`, `accent-soft` og `ink` og farvebehandlingens nås/nås ikke (oktober 2026).
- [SPEC-analysevindue-layout.md](SPEC-analysevindue-layout.md) – analysevinduets fanebjælke, gennemsnitligt antal stik på linjekortene og sidningerne som tabel (udgivet 8. oktober 2026).
- [SPEC-forside-spor.md](SPEC-forside-spor.md) – forsiden med I dag og ét kort pr. spor (udgivet 17. oktober 2026).
- [SPEC-analyse-situation.md](SPEC-analyse-situation.md) – situationen i Analyse: kendte kort, hp-grænser, import og valg af linjer (udgivet 18. oktober 2026).
- [SPEC-notation-sidninger.md](SPEC-notation-sidninger.md) – notationen for sidninger med antal og chance pr. sidning (udgivet 20. oktober 2026).
- [SPEC-neutral-kilde.md](SPEC-neutral-kilde.md) – banken omtales neutralt som "de klassiske farvebehandlinger" (udgivet 20. oktober 2026).
- [SPEC-forbindelser.md](SPEC-forbindelser.md) – begrænsede forbindelser i løseren, panelet Situationen og Spil den selv (udgivet 21. oktober 2026).
- [SPEC-analyse-modul.md](SPEC-analyse-modul.md) – Analyse som eget modul med kort, link i sidefoden og guide (udgivet 21. oktober 2026).
- [SPEC-haandevaluering-kalibrering.md](SPEC-haandevaluering-kalibrering.md) – kalibreringen af P-modellen: trumflængden, HCP-grænsen 23 og nøglekort ved slem (udgivet 22. oktober 2026).
- [SPEC-sprog-og-ordbog.md](SPEC-sprog-og-ordbog.md) – husets fagord, fagordstesten og Bridgeordbog under Opslag i sidefoden; fælles for de tre repoer (udgivet 22. oktober 2026).
- [SPEC-kontaktformular.md](SPEC-kontaktformular.md) – sidefodens link til kontaktformularen på Om mig i stedet for e-mailadressen (udgivet 22. oktober 2026).
- [SPEC-forside-bred.md](SPEC-forside-bred.md) – forsiden på computer fra 1000 px med grupperne side om side, og bridgebordet med kompas i Spil den selv (udgivet 30. oktober 2026; rettet på grenen `forside-bred-2` samme dag).
- [SPEC-beskrivende-form.md](SPEC-beskrivende-form.md) – instruktioner og forklaringer i beskrivende form, ikke i bydeform, og testen for bydeform (udgivet 30. oktober 2026).
- [SPEC-sprog-kipning-toppe.md](SPEC-sprog-kipning-toppe.md) – kipning altid som navneord, toppe farven, frafald kun om hold-up, Toppe eller kipning og linjeteksterne i beskrivende form; banken bygget igen med `LINES_VERSION` 3 (udgivet 31. oktober 2026).
- [SPEC-bred-layout.md](SPEC-bred-layout.md) – alle skærme bredt fra 1000 px efter bud A: højst 1120 px, opgaven i to spalter med bordet i en fast venstre spalte på 420 px, gitre og indstillinger i to kolonner uden bord, vejledningen med indholdsfortegnelse og linjekortenes trin med samme afstand; accepttesten `scripts/tjek-bred-layout.mjs` (udgivet 31. oktober 2026).
